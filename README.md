# Print Ref (15cm-crop)

Crop a photo to a square, resize it to 15 cm, and place it centred on a white A4 JPEG (200 dpi by default) for use as a painting reference.

Runs entirely in the browser — installable as a standalone app on ChromeOS via Chrome's "Install page as app".

Files: `index.html` (the app), `manifest.json`, `sw.js` (offline cache), icons.
